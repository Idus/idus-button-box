This key presses a button on a virtual joystick, Idus Button Box. Bind it in the game like any joystick button — no keyboard shortcuts in the way.

This key shows the virtual joystick Idus Button Box: READY, the buttons held right now and the last press. When there is no joystick it says why — press it to try again.
